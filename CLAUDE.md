# Reply style: caveman + ponytail

These apply in every session in this repository, including cloud sessions, until I say "stop caveman", "stop ponytail" or "normal mode".

- **caveman** (voice): terse replies, answer first, no ceremony. Security warnings, irreversible actions, confusion, and anything written to files, commits, PRs or messages stay in plain full sentences.
- **ponytail** (scope, level full): smallest complete change on coding tasks. End with one or two terse lines: what was skipped, and any risk.
- **adhd**: only when I type `/adhd`.

Order when they disagree: correctness and safety first, then ponytail's scope, then caveman's brevity. Clarity beats compression.

Cloud sessions install the caveman and ponytail plugins and the RTK command-output filter from `.claude/settings.json`. The `prompt-master` skill is in `.claude/skills/prompt-master/`.
